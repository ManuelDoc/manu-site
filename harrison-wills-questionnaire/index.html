Before writing the site

Clear answers now make the finished site feel more accurate.

This questionnaire helps shape the website properly before final content and structure are written. The clearer the answers, the easier it will be to make the site feel professional, specific and useful for the kind of work Harrison wants to attract.

It may also be worth creating a YouTube channel, even if it is only used to host selected portfolio videos for the website. YouTube optimises video delivery for the web, loads quickly across devices, and lets us embed selected videos without making the site heavy. It can also help later with hero/background video sections, case studies, project pages and SEO.

The questionnaire

Twelve focused questions.

Short answers are fine. Links, rough notes and honest preferences are more useful than polished copy.

Submission: this form uses Manuel's existing secure Formspree setup. Responses can later be moved to a dedicated form service if needed.
01 What should the website do first?

Choose the main job of the site. If there are two, mention the priority in the notes.

02 Which work should the website attract more of?

Pick every category that should feel visible on the site.

03 Who are the ideal clients?
04 Which projects should be shown?
05 How should the portfolio be presented?

This affects whether the site feels like a simple reel, a curated portfolio, or a deeper case-study site.

06 Which social platforms should the site use?
07 How should people contact you?
08 What should enquiries ask for?

Select the details that would help qualify a serious project without making the form feel too long.

09 How would you describe your visual style?
10 Should pricing be visible?
11 What brand assets already exist?

Mention what is ready, what needs creating, and where files can be shared.

12 Should photography be included?

Video should stay the main focus unless photography is a clear part of the offer.
